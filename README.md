# Franklin Street Marketing Pages

Published landing pages and decks from the StreetWise marketing hub (https://claude.ai/artifact/HXHGAcrgVThjRsgWdbateS). A page is published here when its project is marked complete in the hub.

Live at https://fsmarketing123.github.io/marketing-pages/

| Folder | Project type |
| --- | --- |
| `report-landing-pages/` | Market Reports Site |
| `pitch-decks/` | Pitch Decks |
| `team-decks/` | Team Decks |
| `business-line-decks/` | Business Line Decks |
| `emails/` | Email Templates (web version; `assets/email/` holds the images Constant Contact emails load) |
| `websites/` | FS Websites (client-branded sites with the Franklin Street footer; password-protected sites are published encrypted) |

Files are named `<platform>-<business line>-<project name>.html`. `assets/` and `fonts/` are shared by every page; photos uploaded in the hub go in `assets/uploads/`. `manifest.json` lists every live page and drives `index.html`.

Do not edit pages here by hand: reopen the project in the hub, change it, and mark it complete again. The new version overwrites the old file.

The publishing steps are in `PUBLISHING.md` in the hub's source folder (`~/Desktop/Claude Code/tampa-mf-brochure`).
